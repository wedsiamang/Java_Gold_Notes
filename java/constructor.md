# コンストラクタ
- final なインスタンスメンバ変数は、そのクラスの「すべてのコンストラクタ経路」で必ず1回だけ初期化されていなければならない。
- finalフィールドは、メソッドでは初期化できない
- オブジェクト生成時は、必ずスーパークラス部分から先に初期化される
- サブクラスのすべてのコンストラクタは、暗黙・明示を問わず必ずスーパークラスのコンストラクタを呼ぶ。
- 引数なし super() が自動挿入されるため、スーパークラスに引数なしコンストラクタがなければコンパイルエラーになる。
- this()とsuper()は同時には書けない
- スーパークラスに引数なしコンストラクタが必須なのではなく、サブクラスが暗黙または明示的に super() を呼ぶ場合にだけ必要。
- 明示的に super(引数…) を書けば、引数なしコンストラクタは不要。
